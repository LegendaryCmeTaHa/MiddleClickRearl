# Middle Click Pearl — Minecraft 1.21.11

Клиентский Fabric-мод. Нажатие средней кнопки мыши бросает эндер-жемчуг.

## Возможности
- Ищет эндер-жемчуг во всём инвентаре игрока: хотбар и основной инвентарь.
- Если жемчуг лежит в основном инвентаре, временно меняет его местами с выбранным слотом хотбара.
- После отправки использования возвращает предметы и выбранный слот на прежние места.
- Не добавляет GUI и команды.
- Клавишу можно изменить в **Настройки → Управление → Назначение клавиш**, категория «Разное» (название зависит от перевода игры).

## Сборка
1. Установи JDK 21.
2. Открой папку `Middle Click Pearl` в IntelliJ IDEA как Gradle-проект.
3. Дождись окончания Gradle Sync.
4. В окне Gradle запусти `Tasks → build → build`.
5. JAR появится в `build/libs/`.

## Установка
Скопируй `middleclickpearl-1.0.1.jar` из `build/libs` в папку `.minecraft/mods`.
Также нужны Fabric Loader и Fabric API для Minecraft 1.21.11.

## Примечания
Проект использует Fabric Loom, Yarn mappings и Java 21. Если Gradle сообщает, что не может разрешить версию зависимости, проверь подключение к интернету и доступность указанных версий Fabric.

## Имя выходного файла
После успешной сборки ожидаемое имя: `middleclickpearl-1.0.1.jar`.

## Исправление build.gradle
В этой версии имя выходного JAR задано напрямую в `build.gradle`; ошибка `unknown property 'archives_base_name'` исправлена.
